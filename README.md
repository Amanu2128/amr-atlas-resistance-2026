# Tracking the Untreatable: Temporal Trends and Machine Learning Prediction of Carbapenem and Third-Generation Cephalosporin Resistance

**2026 Vivli AMR Surveillance Data Challenge**

Analysis of 589,607 WHO-priority Gram-negative isolates from the ATLAS Global Surveillance dataset (2004–2024, 83 countries).

## What's in this repository

- `SO1_SO2_Trends_Distribution.ipynb` — temporal trend analysis and distribution analysis
- `SO5_ML_Prediction.ipynb` — machine learning models and SHAP interpretability
- `requirements_clean.txt` — Python package versions
- `figures/` — all figures generated by the analysis

## Study objectives

1. Temporal trends in carbapenem and 3GC resistance (2004–2024)
2. Distribution of resistance across countries, species, and clinical sources
3. Phenotypic susceptibility patterns
4. Machine learning prediction with SHAP interpretability

## Key findings

- Carbapenem resistance rose from 5.9% (2004) to 18.4% (2024)
- 3GC resistance rose from 20.7% to 36.5%
- *Acinetobacter baumannii* reached 68.6% carbapenem resistance by 2024
- Africa was the only region with significant increases in both drug classes
- Best models: XGBoost (ROC-AUC 0.965, carbapenem) and CatBoost (ROC-AUC 0.966, 3GC)
- Co-resistance features improved all nine tested algorithms (+0.16 to +0.36 ROC-AUC)
